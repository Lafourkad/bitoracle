What is BitOracle?

Bitcoin L1 has no native oracle. This means dApps building on OpNet — Bitcoin's smart contract layer — have no way to access real-world data like price feeds without trusting a centralized third party. That trust assumption defeats the purpose of building on Bitcoin in the first place.

BitOracle solves this with a decentralized network of independent node operators who cryptographically sign real-world data. Instead of trusting a single entity, dApps receive data backed by a threshold of independent signers — making it impossible for any single actor to corrupt the feed.

Key Insight

BitOracle uses a pull model rather than traditional push oracles. Instead of waiting for periodic on-chain updates, dApps embed a fresh oracle signature directly in their transaction. This signature is verified atomically during transaction execution — meaning you always get the latest data without paying for unnecessary updates or waiting for the next push cycle. It's on-demand, pay-per-use, and far more capital efficient.

Security is built on ThresholdML-DSA — a quantum-resistant signing scheme based on FIPS-204, the new post-quantum cryptography standard. No single node can forge a valid signature; it requires agreement from a threshold (t) of the n-node committee. Even if some nodes are compromised, the oracle remains secure.

To keep costs low, BitOracle uses MuSig2 Schnorr signatures. The aggregated signature submitted on-chain is only 64 bytes — dramatically smaller than naive multi-sig approaches. This translates to real savings: approximately $5-10 per oracle update, making Bitcoin-native DeFi economically viable.

Node operators are held accountable through Discreet Log Contracts (DLCs) on Bitcoin L1. Operators stake BTC as collateral, and if they misbehave — submitting fraudulent data or going offline — their stake is automatically slashed. This crypto-economic guarantee ensures nodes have real skin in the game.

Founder Node NFTs give holders the right to operate an oracle node and earn a share of network fees. With only 100 NFTs ever minted, holders receive monthly BTC distributions representing 80% of all oracle fees collected by the network. It's an opportunity to be part of Bitcoin's oracle infrastructure from day one.

Roadmap

Building the future of Bitcoin-native oracle infrastructure

Phase 1 ✅

Price Feeds + MuSig2

Price feeds live on testnet. MuSig2 Schnorr 64-byte on-chain verification. ThresholdML-DSA 3-of-3 quantum-safe signing. 98% cheaper than naive multi-sig.

Phase 2

Founder Node NFT + Committee Sampling

100 Founder Node NFTs. OracleRegistry v4 — NFT-gated node registration. Committee sampling: each round randomly selects a 4-of-6 signing group from active nodes (max 6 per ThresholdML-DSA). Monthly BTC fee distribution to NFT holders.

Phase 3

VRF + Multi-Asset Feeds

Verifiable randomness for gaming and NFT projects on OpNet. Expanded price feeds: ETH/USD, BTC/EUR, stablecoins. Deviation threshold + heartbeat update model.

Phase 4

Proof of Reserve + DKG

Trustless reserve verification for wBTC and stablecoins on OpNet. Distributed Key Generation (DKG) for committee key rotation without changing the on-chain public key.
