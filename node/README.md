# BitOracle Node

Oracle daemon for price feed signing and API server.

## Setup

```bash
cd node
npm install --legacy-peer-deps

# Generate your keys
node --import tsx/esm src/scripts/kit/generateKeys.ts

# Mint your NFT
node --import tsx/esm src/scripts/kit/mintNFT.ts

# Register your node
node --import tsx/esm src/scripts/kit/registerNode.ts --token <tokenId>

# Run the daemon
source node.env && node --import tsx/esm src/scripts/runDaemon.ts
```

## Architecture

```
runDaemon.ts
    │
    ├── PriceCache.ts         # Fetch from Binance, Coinbase, Kraken
    ├── MuSig2.ts             # Aggregate signatures
    ├── HttpServer.ts         # Expose /signed-price API
    └── OracleNode.ts         # P2P coordination (future)
```

## API

| Endpoint | Description |
|----------|-------------|
| `GET /health` | Node status |
| `GET /signed-price?asset=BTC/USD` | Price + signature |
| `GET /signed-prices` | Batch all assets |
| `GET /status` | Full node info |
